# DAST: процес динамічного тестування

## 1. Запуск сканування
Динамічне тестування (DAST) виконується за допомогою інструменту OWASP ZAP (ZAP Baseline Scan) на етапі CI/CD конвеєра, а також локально для перевірки розгорнутого Docker-контейнера.

## 2. Результати сканування (Висновки)
Під час динамічного аналізу розгорнутого застосунку було підтверджено наступні вразливості:
- **SQL Injection (SQL впровадження):** виявлено можливість маніпуляції базою даних через невідфільтровані параметри.
- **Cross-Site Scripting (Міжсайтовий сценарій / XSS):** виявлено можливість ін'єкції шкідливого скрипта.
- **Відсутність безпекових заголовків:** відсутні Anti-CSRF токени, X-Content-Type-Options та захист від клікджекінгу.

## 3. Рекомендації
Результати DAST повністю підтверджують знахідки SAST та моделі загроз. Необхідно впровадити параметризовані запити (використовувати підготовлені вирази замість прямої конкатенації), екранування вводу/виводу та налаштувати HTTP-заголовки безпеки.
