# SAST: процес керування та тріажу

## 1. Запуск сканування
CI/CD конвеєр автоматично запускає інструменти `semgrep`, `bandit` та `pip-audit` на кожен push.

## 2. Обробка результатів
Результати сканування публікуються як артефакти у вкладці Actions.

## 3. Правила тріажу та створення задач
- **High/Critical**: створюється задача в Issue Tracker із тегом `security`.
- **Medium/Low**: створюється задача в беклозі або позначається як `false positive`.

## 4. Процес виправлення
Розробник виправляє код і створює PR з посиланням на Issue. Після злиття коду та повторного сканування задача закривається.
